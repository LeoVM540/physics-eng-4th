## Adding a new subject
1. Create a folder `uni/<subject>/` (e.g. `notes/`, `exams/`, `formula_sheet/`).
2. Add a row to the table above.
3. `git add . && git commit -m "Add <subject>" && git push`

LaTeX build files are ignored; compiled PDFs are committed so they can be read on GitHub directly.
